# 心理危机监测与预警系统

基于社交媒体文本语义挖掘的科研展示网站，围绕用户级心理症状线索、热点事件情绪与目标立场开展分析。网站将模型结果、时间变化和脱敏原文组织在同一界面中，支持从统计概览进入具体文本进行人工核对。

本仓库提供项目的静态网页版本，使用 HTML、CSS、JavaScript、Plotly.js 和 JSON 数据，部署于 GitHub Pages。

[访问网站](https://youngzz-lil09.github.io/mental-health-research/) · [隐私说明](privacy.html) · [问题反馈](https://github.com/youngzz-lil09/mental-health-research/issues)

## 主要功能

| 栏目 | 内容 |
| --- | --- |
| 首页 | 项目简介、数据与版本状态、使用说明及后续研究方向 |
| 本地文本推理 | 同一用户多条动态的输入界面；静态版本暂未接入模型推理 |
| 普通用户分析 | 样本构成、九维预测汇总、时间变化、地区分布，以及用户筛选和详情浏览 |
| 热点专题分析 | 专题背景、样本讨论量、情绪与目标立场的时序变化、事件节点，以及文本浏览和复核候选筛选 |
| 模型评测与边界 | 共同测试集性能、逐维指标、混淆矩阵、AUC、概率校准、效率与成本，以及历史语境迁移实验 |

用户与热点文本列表支持筛选、排序、分页和详情查看。选择记录后，可查看相应模型概率、证据文本或脱敏原文。人工复核目前提供候选浏览与筛选，标签和备注的保存尚未接入。

## 数据与分析场景

### 普通用户分析

当前包含 **749 名匿名用户、18,207 条公开原创动态**，展示 PHQ-9 九维症状线索的预测概率、阈值、0/1 标签、连续人工复核分数及复核优先级，并提供性别、省级 IP 属地和时间变化分析。

该场景使用 RoBERTa `seed2026` 的离线分析结果，采用最多 12 个文本窗口和 Top-2 聚合。

### 热点专题分析

主界面展示以下五个专题的默认最新版本，历史数据另行保留。

| 专题 | 评论数 | 普通动态数 |
| --- | ---: | ---: |
| 赣南学生虐猫事件 | 710 | 405 |
| 重庆山姆打包哥被指虐待动物事件 | 671 | 100 |
| 动物保护与反虐待讨论 | 701 | — |
| 星宇股份劳动合同争议 | 1,556 | — |
| 襄阳医院与患者权益专题 | 1,576 | 1,183 |

“—”表示该版本未提供对应文本层数据。各专题按实际数据展示六分类情绪预测，以及指定命题下的支持、反对、中立三分类立场预测。评论与普通动态分别统计，不同命题分别解释。

时序区域集中展示采集样本讨论量、情绪比例、目标立场比例及已有事件节点。曲线呈现已采集样本的历史变化，趋势预测和自动采集尚未接入。

### 模型性能评测

RoBERTa `seed42` 与 GLM 在共同 **500 名测试用户**上进行九维标签比较，展示总体及逐维 Precision、Recall、F1，以及混淆矩阵、概率质量和推理效率。此处评测对应 `seed42`，与普通用户分析使用的 `seed2026` 分别标注。

历史 RoBERTa 语境迁移实验保留 3 个来源帖、248 条评论、228 名匿名评论者的探索性结果与案例。

## 使用与结果阅读

进入栏目后，先确定专题、数据版本、文本层及立场命题，再查看图表和具体记录。图表与统计表随适用筛选条件更新；详细原文可在用户或文本列表中选择查看。

系统结果用于科研分析和人工复核辅助，不构成心理或医学诊断。复核优先级表示人工查看顺序；热点预测比例描述本次采集样本。详细说明见网站“使用声明”和[隐私说明](privacy.html)。

## 技术与文件结构

图表和数据处理在浏览器中完成，数据按栏目、专题及用户动态分批加载。网页使用随项目提供的 Plotly.js，无需服务器端模型或数据库。

```text
index.html                  网站入口
privacy.html                隐私说明
assets/                     页面交互、样式与 Plotly.js
data/                       数据索引、统计结果与脱敏明细
tools/                      离线数据导出与发布检查工具
THIRD_PARTY_NOTICES.md       第三方资源说明
```

`tools/build_public_data.py` 用于从完整研究工程导出网页数据，依赖原工程的数据与环境；GitHub Pages 运行时不执行该工具。`tools/verify_public.py` 用于检查发布包的数据结构、统计一致性及隐私字段。

## 本地预览

安装 Python 后，在仓库根目录打开终端并运行：

```powershell
py -m http.server 8080 --bind 127.0.0.1
```

浏览器访问 `http://localhost:8080`。通过本地 HTTP 服务预览可正常加载 JSON 数据；直接双击 HTML 文件可能受浏览器文件访问限制。
